# ArguMentor Junior · 第一版

给小学六年级、逐步进入初中英语水平的孩子使用。先练清楚表达，再慢慢练回应和比较理由。

## 可以先体验什么

1. 在「练习空间」或「议题书架」选一个议题。
2. 选择支持或反对，查看词汇，然后进入练习。
3. 完成四轮：表达观点 → 回应对方 → 比较理由 → 完成总结。
4. 每轮查看教练笔记；结束后查看逐轮复盘和论证关系图。
5. 论证图可以点击查看原句、编辑 Argdown 源码、下载 `.argdown` 文件。

共有 50 个议题、5 个等级，每级 10 个。建议从 Level 1 开始，不要求一开始就写很长。计时器是可选的，不会到点自动提交。每一轮的灯泡按钮现在提供三层提示：句型、该议题的思路库、自查问题。

## 示范模式与自由辩论的区别

- **当前示范模式**：预设反方观点，加上针对连接词等结构的提示。可以体验完整流程，但不是针对孩子内容自由生成的 AI 辩论，也没有 AI 质量评分。
- **自由辩论模式**：本地服务器配置模型密钥后可用。模型根据孩子发言生成回应、优点、一项改进和英文改写。评分只是学习反馈，不是正式测评。
- 私有线上展示版只运行示范模式。模型接口在本地版本中，不把密钥放进网页。

## 本地启动

在此目录打开终端：

```sh
npm run dev
```

访问 `http://127.0.0.1:4187`。仅监听本机；如果端口已经被使用，启动会失败，不会抢占端口或关闭其他程序。

依赖已经安装。将来重新下载时，用 `npm install --workspaces=false` 安装本子项目依赖，不需要安装上游所有项目。

正式构建运行：

```sh
npm run build
npm start
```

## 接入模型

在本目录创建 `.env.local`，参考 `.env.example`。选择其中一种：

```dotenv
OPENAI_API_KEY=在本机填入自己的密钥
DEBATE_MODEL=gpt-4.1-mini
```

或：

```dotenv
OPENROUTER_API_KEY=在本机填入自己的密钥
DEBATE_MODEL=openai/gpt-4.1-mini
```

只重启本项目服务。密钥不要发送到聊天或提交到 Git；`.env.local` 已被 Git 忽略。模型调用可能产生供应商费用。界面检测到密钥配置不代表已验证额度或模型访问权限。

## 数据、语音和复盘边界

- 练习和草稿保存在当前浏览器；换浏览器不会自动同步。可在练习记录中导出 JSON。
- 请勿在练习中输入孩子的姓名、学校、住址等个人资料。自由辩论会将发言和本场历史发送给所选模型供应商。
- 语音输入有两条路径：支持 Web Speech API 的浏览器会直接识别；本地配置 `OPENAI_API_KEY` 后，则录音并调用 OpenAI 转写接口。建议使用最新版 Chrome。提交前可以修改转写文字。
- 本应用不保存音频，但浏览器供应商可能在线处理语音识别。文本反馈不能评价真实发音。
- 论证图根据回合的支持/反对角色生成，不是已经核实的语义分析。请结合原文判断，可自行调整关系。
- 第一版采用简化 Public Forum 四轮练习，不是完整比赛规则。

## 项目隔离

新增应用位于 `argumentor/apps/junior`，使用独立依赖和 4187 端口。没有关闭其他项目、修改系统依赖或覆盖同目录下的其他项目。

实际复用了 ArguMentor 的辩论配置和状态机；只将其 TypeScript 共享配置改成等价的相对路径，以支持独立构建。DebateSim 用作教学流程参考，没有复制其代码。Argdown 通过正式依赖接入。
