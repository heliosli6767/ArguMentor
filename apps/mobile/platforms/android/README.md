# Android release boundary

- Package: `app.argumentor.junior` (placeholder until the owner confirms Play Console ownership).
- Request `RECORD_AUDIO` only at the moment the learner taps the microphone.
- Declare data safety and child/family policy behavior before public distribution.
- Keep purchases in Google Play Billing and resolve entitlements on the server.
- Test small phones, tablets, low-memory devices, interrupted uploads and restricted networks.

Generate `android/` with Expo prebuild only when native configuration is required; use `.android.ts(x)` adapters for intentional platform differences.
