# ArguMentor Junior — WeChat Mini Program

Native WeChat shell for the Junior learning experience. Open this directory in WeChat DevTools; set the real AppID in the local project settings and register the production HTTPS API domain before network testing.

The included flow works as an offline teaching scaffold: home → learning/motions → briefing → four-round demo → review. Live AI, transcription, login and cloud sync remain server integrations and must not contain provider keys.

See `docs/junior-platform/platform-boundaries.md` and `services/junior-api/openapi.yaml`.
